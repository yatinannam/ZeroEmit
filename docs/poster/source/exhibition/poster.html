ZeroEmit: AI-Powered
Carbon-Aware EV Charging

Charge your EV when India's grid is cleaner.

Problem statement

  • An EV is only as clean as the power that charges it, and most of India's electricity still comes from coal.
  • Grid carbon intensity swings through the day: on the Southern grid, 513 gCO₂/kWh at noon but 781 at 8 pm.
  • Drivers can't see this, so they charge by habit, often in the evening, when each kWh emits the most CO₂.

Proposed solution

ZeroEmit is a free web app that EV drivers install on their phone. It reads the live carbon intensity of the driver's regional grid, forecasts the next 24 hours and tells them when to plug in.

  • Know the best time

    The cleanest 2-hour windows for today and tomorrow, for the driver's city.

  • Get reminded

    A notification before the best window starts.

  • See the impact

    Each logged charge shows the CO₂ it avoided and earns points for good timing.

Methodology and system architecture

Data sources

  • India Energy Atlas grid data
  • Electricity Maps fallback
  • OpenStreetMap chargers

Server on Vercel

  • Next.js API routes
  • Upstash Redis cache
  • Scheduler every 15 min

Carbon-aware decision engine

  • Forecast, rank, nudge, score
  • Explainable rules on real grid data

ZeroEmit app

  • React 19 web app
  • Works offline
  • Push notifications
  1. Read the current carbon intensity of the driver's regional grid, cached on the server.
  2. Forecast a typical day: the average for each hour over the last 14 days, with the live reading for the current hour.
  3. Rank every 2-hour window in the next 24 hours by average intensity; keep the 3 cleanest that don't overlap.
  4. Nudge with a push reminder before the best window, and an alert when now is the cleanest time left.
  5. Score each logged charge: +10 points in a best window, +5 at a cleaner-than-average hour. CO₂ avoided = (650 − intensity at charging) × kWh.
